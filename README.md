# Студия Точка

## Автоматические ударения

Встроена словарная проверка на основе MIT-словаря проекта zdarsch/russian-stress-marker, версия 1cd1a1555f01bbbaeebb2d4fd15fe5e9d52c9a37. Словарь встроен в страницу; при словарной проверке текст пользователя не отправляется сторонним сервисам. Лицензия включена в HTML и vendor-accent/LICENSE.txt.

Нажмите «Проверить и предложить ударения», просмотрите результат и список слов для ручной проверки, затем «Применить ударения». Цвета и существующие ударения сохраняются. Кнопка отмены возвращает состояние до обработки, если после неё не менялись текст или цвета.

Это словарный помощник, а не гарантия произношения. Контекстные омографы, имена, редкие и старинные слова требуют редакторской проверки. Режим старинного / церковнославянского текста использует только личный словарь. Вручную поставьте проверенное ударение, оставьте курсор в слове и нажмите «Запомнить ударение слова». Личный словарь переносится в файле проекта вместе с текстом.

Исследованные альтернативы: RUAccent (https://github.com/Den4ikAI/ruaccent) для контекстной серверной обработки; Onik (https://github.com/EliseyP/onik) для церковнославянской редакторской обработки. Они не встроены в эту версию. Полная церковнославянская акцентуация и восстановление исторической орфографии не реализованы.

Браузерный телесуфлёр с прокруткой текста, зеркальным режимом, настройкой шрифта и скорости, выбором камеры и микрофона и записью видео со звуком.

## GitHub Pages

В настройках репозитория откройте Settings → Pages. Выберите Deploy from a branch, ветку main и папку / (root), затем сохраните. Главная страница — index.html.

## Локальный запуск

Запустите `python studio-server.py` и откройте http://localhost:8766/.

## RØDE Wireless GO II

Подключите приёмник RX к компьютеру USB-кабелем с передачей данных. Разрешите доступ к камере и микрофону, выберите Wireless GO II и нажмите подключение повторно. Сделайте пробную запись и проверьте её звук.

## Ограничения

Для камеры и микрофона требуется HTTPS или localhost. Видео сохраняется в памяти вкладки до скачивания; для долгих записей нужна доработка. Текст сохраняется в браузере. Видео и текст не отправляются на сервер. Управление с другого компьютера пока не реализовано. Проверка записи на реальном оборудовании ещё не выполнена.

## Ударения на слове и во всём русском тексте

Выделите гласную или целое слово и нажмите «Ударение». Словарные слова получают ударение сразу, для неоднозначного слова появляется выбор гласной. Галочка «Расставить ударения во всём русском тексте» сразу применяет словарь ко всему тексту и повторяет обработку при вводе. Неоднозначные слова остаются для проверки. Снятие галочки сохраняет поставленные знаки; последнее автоматическое применение можно отменить.

Для контекстной ИИ-проверки откройте раздел «ИИ — проверка русского текста по контексту» и введите личный ключ OpenRouter. Используется исключительно модель openrouter/free без платных резервных моделей. Ключ остаётся в поле текущей вкладки, не сохраняется в localStorage, репозитории и проекте. Только нажатие кнопки ИИ передаёт текст OpenRouter и поставщику модели. Бесплатные лимиты и доступность устанавливает сервис. Максимум одной проверки — 30 000 символов, части до 3200 символов расходуют отдельные запросы. Переписанные буквы, пробелы, пунктуация, прежние ударения или несколько ударений в слове приводят к отклонению ответа. Предложения ИИ требуют просмотра и отдельного применения; правильность произношения не гарантируется. Реальный API-запрос требует пользовательского ключа и без него не проверялся.

Ссылки: https://openrouter.ai/docs/guides/routing/routers/free-router и https://openrouter.ai/docs/api_reference/limits .

## Вид текста в эфире

Две независимые кнопки под экраном: «Ударения в эфире: вкл./выкл.» и «Выделения в эфире: вкл./выкл.». Они управляют только экраном суфлёра, включая полноэкранный режим. Редактор, предпросмотр разметки, сохранённый файл и личный словарь не изменяются. Отдельное сетевое управление другим компьютером не добавлено.

## Развёрнутый предпросмотр разметки
Кнопка «↗ На весь экран» рядом с предпросмотром разворачивает его вместе с палитрой цветов на всю рабочую область браузера. Выделите фрагмент прямо в большом тексте и нажмите цвет. «↙ Вернуть предпросмотр» или Escape возвращает прежний вид; разметка и исходный текст сохраняются. В большом окне текст прокручивается отдельно, палитра остаётся доступной сверху.
