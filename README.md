# Студия Точка

Браузерный телесуфлёр с прокруткой текста, зеркальным режимом, настройкой шрифта и скорости, выбором камеры и микрофона и записью видео со звуком.

## GitHub Pages

В настройках репозитория откройте Settings → Pages. Выберите Deploy from a branch, ветку main и папку / (root), затем сохраните. Главная страница — index.html.

## Локальный запуск

Запустите `python studio-server.py` и откройте http://localhost:8766/.

## RØDE Wireless GO II

Подключите приёмник RX к компьютеру USB-кабелем с передачей данных. Разрешите доступ к камере и микрофону, выберите Wireless GO II и нажмите подключение повторно. Сделайте пробную запись и проверьте её звук.

## Ограничения

Для камеры и микрофона требуется HTTPS или localhost. Видео сохраняется в памяти вкладки до скачивания; для долгих записей нужна доработка. Текст сохраняется в браузере. Видео и текст не отправляются на сервер. Управление с другого компьютера пока не реализовано. Проверка записи на реальном оборудовании ещё не выполнена.
